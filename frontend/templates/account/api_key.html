How to call it

  "{{ url_for('api.validate', _external=True) }}?student_id=12&date=2026-10-27"

Answer (200):

{"excused": true, "student_id": 12, "student_name": "Ana Popescu",
 "date": "2026-10-27", "lab_day": true, "slot": "TUE_18_20", "slot_label": "Tuesday 18–20",
 "reported": true, "motivated": true, "absence_id": 5, "until": "2026-10-27"}

excused is true only for an active absence marked motivated. The student ids are in the URL of each student's page (/students/<id>).
